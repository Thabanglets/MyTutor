Part 1: Installation & Setup Instructions

1.1 Prerequisites

Before installing or building the application, ensure your environment meets the following requirements:

  • IDE: Android Studio (Jellyfish, Ladybug, or 2026.1+)
  • JDK: Java Development Kit (JDK 11 or JDK 17)
  • Android SDK: API Level 36 (Compile SDK), Min SDK 27
  • Target Platform: Android Phone or Virtual Device (AVD) running Android 8.0 (Oreo) or higher.

1.2 Build Commands (Gradle)

Run the following commands in the project terminal or PowerShell:

# Build Debug APK
./gradlew app:assembleDebug

# Run Local Unit Tests
./gradlew app:testDebugUnitTest

# Assemble Instrumented Android Tests
./gradlew app:assembleDebugAndroidTest
Build Artifact Location: Generated Debug APK is output to:
app/build/outputs/apk/debug/app-debug.apk

Part 3: User Manual & Help Guide

3.1 Role Overview

  • Students: Filter tutors by city and subject, book interactive sessions, track learning progress, and generate attendance/grade reports.
  • Tutors: Manage lesson schedules, grade student performance, set attendance status, and track total session earnings.
  • Admins: Manage pending account approvals and review all active tutoring sessions.

3.2 Student Features

  1. Finding a Tutor: Open the Find Tutor tab, select a subject (e.g. Mathematics, Science, Programming) and city location (e.g. Cape Town, Johannesburg, Durban), then tap Apply Filter.
  2. Booking a Lesson: Pick a date on the calendar and tap BOOK LESSON next to your selected tutor.
  3. Viewing Reports: Tap Stats -> Generate Report to view an academic summary displaying attendance rate and grades.

3.3 Profile & Settings Features

  • Account Info: Edit Full Name, Location, and Bio. Empty fields display clean placeholders (e.g., Location (City)).
  • Dark Mode Theme: Toggle the Dark Mode Theme switch to immediately apply dark mode across all screens.
  • Session Notifications: Toggle lesson reminder alerts.
  • Help & Support: Tap Help & Support to open support contact information.
